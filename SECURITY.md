# Security policy

## Reporting a vulnerability

Please do not post credentials, tokens, private server addresses, or working exploit details in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is available. If private reporting is not enabled, open an issue containing only a short request for a private security contact and wait for maintainer instructions.

Reports should include the affected version or commit, the part of the application involved, reproduction steps that do not expose real credentials, and the impact you observed.

Security issues in the GameServer itself should be reported to the maintainers of that repository rather than through this front end.
